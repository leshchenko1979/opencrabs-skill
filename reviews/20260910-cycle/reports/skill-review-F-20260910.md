## 2. Detailed Findings by Severity

### HIGH SEVERITY

#### F-HIGH-01: Insecure & Predictable PID-based `/tmp` File Collision in `oc-rebase-safety`
- **Location:** `/root/.opencrabs/profiles/ops/skills/opencrabs-dev/tools/oc-rebase-safety:49, 52, 60, 69, 74, 98, 100, 116, 117`
- **Description:** `oc-rebase-safety` constructs temporary files using PID suffix patterns (`/tmp/ors.main.$$`, `/tmp/ors.merge.$$`, `/tmp/ora.a.$$`, `/tmp/ora.b.$$`). In concurrent multi-agent environments or container namespaces where PIDs can collide or recycle, fixed predictable paths in `/tmp` create race conditions, symlink hijacking vulnerabilities, and potential cross-agent file clobbering.
- **Verbatim Excerpt (`oc-rebase-safety:49-61`):**
  ```bash
  git -C "$repo" diff --name-only "$old_main" "$new_main" | sort -u > /tmp/ors.main.$$ || die 3 "git diff failed"
  git -C "$repo" diff --name-only "$merge_base" "$branch" | sort -u > /tmp/ors.merge.$$ || die 3 "git diff failed"
  
  inter="$(comm -12 /tmp/ors.main.$$ /tmp/ors.merge.$$ | grep -v '^$' || true)"
  rm -f /tmp/ors.main.$$ /tmp/ors.merge.$$
  ```
- **Remediation:** Replace fixed `/tmp/*.$$` paths with `mktemp` / `mktemp -d` and clean up using an `EXIT` trap:
  ```bash
  tmp_dir="$(mktemp -d /tmp/oc-rebase-safety.XXXXXX)"
  trap 'rm -rf "$tmp_dir"' EXIT
  ```

---

#### F-HIGH-02: Missing Unified Tool Log (`lib/oc-log.sh`) Lifecycle in `oc-ship-chain`
- **Location:** `/root/.opencrabs/profiles/ops/skills/opencrabs-dev/tools/oc-ship-chain`
- **Description:** `tools/RC-CONTRACT.md` mandates that all standalone executable tools source `tools/lib/oc-log.sh` and hook into exit traps via `oc_log_finish $?` to record execution telemetry into `tools.log`. `oc-ship-chain` (the high-impact orchestrator) completely omits `_OC_LIB` sourcing and `oc_log_init` / `oc_log_finish` calls, leaving execution chains untracked in unified tool logs.
- **Remediation:** Wire `lib/oc-log.sh` into `oc-ship-chain`:
  ```bash
  _OC_LIB="$(cd "$(dirname "$0")" && pwd)/lib/oc-log.sh"
  if [ -f "$_OC_LIB" ]; then
    . "$_OC_LIB"
    oc_log_init "$@"
    trap 'oc_log_finish $?' EXIT
  fi
  ```
